# Minto Pyramid Principle — Communication Skill

> Lead with the conclusion. Support it with key arguments. Back those with detailed evidence.

A [skills.sh](https://skills.sh) agent skill that structures any business communication — emails, Slack messages, reports, presentations, and slide decks — using the **Minto Pyramid Principle**.

## What it does

- **Written communication**: Restructures emails, messages, and reports into conclusion → arguments → details
- **Presentations**: Maps the pyramid to a slide deck (Slide 1 = Key Message/SCQA, Supporting slides = Arguments + Data, Final slide = Conclusion)
- **BLUF**: Applies "Bottom Line Up Front" so busy audiences get the main message first
- **MECE**: Ensures key arguments are Mutually Exclusive and Collectively Exhaustive
- **SCQA**: Uses Situation > Complication > Question > Answer for presentation introductions

## Install

```bash
npx skills add dananabel-netizen/minto-pyramid --skill minto-pyramid --agent '*' --yes --copy
```

## When it triggers

- Writing or restructuring an email, Slack message, memo, or report
- Building a slide deck or presentation
- "Make this clearer", "make it more concise", "structure this better"
- Mentions of Minto, BLUF, pyramid principle, or conclusion-first communication
- Drafting executive summaries or recommendations
